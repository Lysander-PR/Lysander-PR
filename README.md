### 🚀 Featured Project — Entertainment Catalog API

A RESTful API for managing a multimedia catalog (movies, books, albums, songs), built to practice production-grade backend patterns:

- JWT authentication with role-based authorization (admin/user)
- Redis caching with namespaced, targeted invalidation
- SERIALIZABLE transactions with automatic compensation for file uploads (no orphaned storage objects)
- 93.5% statement coverage, 81.7% branch coverage (Jest + Supertest)
- CI/CD with GitHub Actions: tests against real PostgreSQL/Redis, automatic semantic versioning, multi-arch Docker images
- Deployed on AWS with Docker and NGINX
